# alexandrosdellios.github.io

Personal portfolio of **Alexandros Dellios**, Robotics M.Sc. student at EPFL.
Live at **https://alexandrosdellios.github.io**.

A static site: a short home page (selected work, experience, toolbox, contact) and one page per project.
The design direction is "Lab Poster": warm paper, ink, one bold accent per page, a giant condensed
name strip, serif statements and small mono "telemetry" labels.

## Stack

- [Astro](https://astro.build) 7, static output, native cross-document view transitions
- [GSAP](https://gsap.com) 3 (ScrollTrigger, SplitText) and [Lenis](https://lenis.darkroom.engineering) for motion, bundled from npm
- Self-hosted fonts via Fontsource: Anton, Instrument Serif, Geist, Geist Mono
- `@astrojs/sitemap` for `sitemap-index.xml`
- Deployed by GitHub Actions to GitHub Pages

Everything readable works without JavaScript; motion is progressive enhancement and is switched off
under `prefers-reduced-motion`.

## Commands

Requires Node 22.22 or newer.

```sh
npm install        # install dependencies
npm run dev        # dev server at http://localhost:4321
npm run build      # production build into dist/ (first checks for iCloud conflict copies)
npm run preview    # serve dist/ locally
npm run check      # type-check .astro and .ts files
```

## Folder structure

```
src/
  content/projects/   one Markdown file per featured project (frontmatter = tile + page data, body = prose)
  content.config.ts   the project schema (what each Markdown file must contain)
  data/site.ts        all other home-page copy: identity, Now cards, experience, toolbox, footer line
  assets/             images that Astro optimises (project posters and figures, portrait)
  components/global/  shared components (header, footer, pills, chips, video, placeholders, …)
  components/home/    home sections (hero, Now cards, work grid tiles, more work, experience, toolbox)
  components/project/ project-page parts (title strip, meta row, TL;DR, hero, gallery, prev/next)
  layouts/            BaseLayout (head, header, footer, motion script), ProjectLayout (/work/<slug>/)
  pages/              routes: home, work/[slug] project pages, /cv (redirect to the PDF), 404
  scripts/core/       shared client scripts (smooth scroll, menu, video manager, heading reveals)
  scripts/home/       home motion (name-strip collapse, role rotator, tile entry, stickers, previews)
  scripts/project/    project-page motion (title strip, reading progress fallback)
  styles/             design tokens, fonts, base styles, shared component styles, view transitions
public/
  media/<project>/    looping videos (mp4 + webm) and their posters; served as-is
  og/                 social preview images: default.png, plus <slug>.png per project
                      (generated by scripts/og/make_og_images.py; a page uses its own if it exists)
  CV-Alexandros-Dellios.pdf
  favicon.svg, favicon.ico, apple-touch-icon.png, robots.txt
scripts/og/           Python generator for the social images (default + one per project; see its docstring)
scripts/media/        render_svg.py (SVG poster → PNG with the site fonts), make_icons.mjs (favicon.ico + touch icon)
scripts/check-icloud-copies.mjs   prebuild guard against "name 2.ext" conflict copies
docs/                 project notes: decisions, design system, content and media plans, progress
```

`Images/` (raw media from Alexandros), `private/` (research notes) and `docs/QUESTIONS.md` (open
questions about specific repos and courses) are **local only** and gitignored. Never commit them.

**Keep this folder out of iCloud Drive / Dropbox.** Sync clients write conflict copies
("index 2.html", "polymander 2.md") and restore deleted files; a copy in `src/content/projects/`
would be published as an extra project. `.gitignore` excludes such copies and `npm run build`
stops if one appears in `src/` or `public/`. Move the repo to e.g. `~/Developer/` and run
`rm -rf dist .astro` once.

## Adding a project

1. Create `src/content/projects/<slug>.md`. Copy an existing file and fill in the frontmatter;
   `src/content.config.ts` lists every field and the build fails if one is missing.
2. Put the poster and figures in `src/assets/projects/<slug>/` and reference them with relative paths
   from the frontmatter.
3. Put short looping videos in `public/media/<slug>/` (H.264 `.mp4` + VP9 `.webm`, under ~600 KB,
   no audio). Encoding recipes are in `docs/MEDIA.md` §2. A longer clip that should only start from
   its play button gets `clickToPlay: true` in `extraVideos`.
4. Pick an accent pair (`accent` for fills, `accentInk` for small text with AA contrast on paper).
5. Run `npm run dev` and check the tile on the home page and the project page.

If the media is not ready yet, set `mediaNeeded` and the site shows a visible placeholder instead.

## Deployment

Every push to `main` runs `.github/workflows/deploy.yml`: it installs dependencies, runs
`npm run build`, and publishes `dist/` to GitHub Pages. It can also be started by hand from the
**Actions** tab (workflow_dispatch).

One-time setup on GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

A custom domain can be added later with a `public/CNAME` file and the matching `site` in
`astro.config.mjs`.
